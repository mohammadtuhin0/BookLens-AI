
# BookLens AI — Product Requirements

## 1. Project Overview

BookLens AI is an AI-powered web application
that helps users understand books through
cover images and digital documents.

## 2. Problem Statement

Users often struggle to identify a book's
subject, understand its content, and discover
whether it is suitable for their learning goals.

## 3. Target Users

- University Students
- Researchers
- Book Readers
- Developers
- Self-learners

## 4. Functional Requirements

### FR-01: Book Cover Upload

Users can upload JPG, JPEG and PNG images.

### FR-02: Text Extraction

The system extracts text from book cover images.

### FR-03: Book Identification

The system identifies book title and author
when sufficient information is available.

### FR-04: Book Classification

The system predicts the book's subject
and category.

### FR-05: AI Description

The system generates a description of the book.

### FR-06: PDF Processing

Users can upload PDF documents.

### FR-07: AI Question Answering

Users can ask questions about uploaded books.

## 5. Non-Functional Requirements

- Security
- Reliability
- Maintainability
- Scalability
- Performance
- Usability
- Testability

## 6. MVP Scope

Version 0.1 focuses on:

- Image upload
- OCR
- Book identification
- Book classification
- AI-generated description

## 7. Future Scope

- PDF understanding
- RAG-based chatbot
- Multiple document support
- Book recommendations
- Multilingual support
