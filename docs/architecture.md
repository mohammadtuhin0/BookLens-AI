
# BookLens AI — System Architecture

## 1. Architecture Overview

BookLens AI follows a modular architecture.

## 2. Main Components

### Frontend

React and TypeScript.

### Backend

Python and FastAPI.

### Computer Vision

OpenCV and OCR.

### AI Layer

LLM APIs and open-source models.

### Database

PostgreSQL.

### Vector Database

ChromaDB.

## 3. Main Processing Flow

1. User uploads an image.
2. Frontend sends the image to the backend.
3. Backend validates the image.
4. OCR extracts text.
5. AI analyzes extracted information.
6. Backend returns structured results.
7. Frontend displays the results.

## 4. Future Architecture

integrated in future versions.
